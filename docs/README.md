# Guides

One guide per part of the tool. Start with the task table in [../USER_GUIDE.md](../USER_GUIDE.md).

Each guide follows the same layout: what it does → run it → read the result → options →
limits → next step.

When a command, flag or output changes, update the matching guide here (and the task table in
`USER_GUIDE.md` if a task is added or removed).
